Comprehensive web booking engine built with Laravel & Vue.js, coupled with a dedicated cross-platform mobile application developed with Flutter at Nadas Group.

Visit Live Platform View App Gallery

Project Overview

Tunisia Go Travel is a leading travel reservation ecosystem in Tunisia designed to streamline hotel reservations, vacation packages, desert excursions, and flight bookings for international and local tourists.

As Senior Full Stack Developer at Nadas Group, I architected both the reactive web frontend, the backend REST API infrastructure with Laravel, and engineered the high-performance Flutter mobile application for iOS and Android.

Key Responsibilities & Deliverables

  • Full-Stack Architecture: Engineered scalable backend micro-endpoints using Laravel with fast database caching and relational schemas.
  • Flutter Mobile App: Built the official cross-platform mobile application for Android and iOS with seamless offline caching, intuitive booking wizard, and push notifications.
  • REST API Gateway: Designed secure, token-authenticated RESTful API endpoints for seamless web and mobile synchronization.
  • DevOps & Linux Server: Deployed and managed production services on Linux, optimizing server response times and database indexing.
