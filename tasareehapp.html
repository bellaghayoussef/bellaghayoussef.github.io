Tasareeh Mobile App

Cross-platform mobile application built with Flutter allowing field inspectors to scan, verify QR permits, and record inspection outcomes in real time.

View Web Platform Mobile Screenshots

Project Overview

The Tasareeh mobile application serves as an on-the-ground inspection companion tool for site agents. Built using Flutter and Dart, it connects via secure REST APIs to the main Laravel backend.

Key Mobile Features

  • Offline Inspection Sync: Cache permit data locally so field officers can conduct audits even without active cellular network coverage.
  • High-Speed Camera Scanner: Instant hardware camera integration for rapid QR code scanning and verification.
  • Audit Logging & Geolocation: Automatically records GPS coordinates and inspection timestamps on submission.
